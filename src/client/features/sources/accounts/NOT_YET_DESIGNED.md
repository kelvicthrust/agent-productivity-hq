# Account controls added after the prototype

Sources offers **Show Claude plan limits** and displays the last check, the returned windows and
any recovery action. A recorded status-line installation also has a manual removal panel. The
owner restores the recorded setting and verifies removal before Agent Productivity HQ deletes its hook files.

The [production design mapping](../../../../../docs/tech/design-to-code.md#product-follow-up)
and [account report contract](../../../../../docs/tech/data-and-sources.md#claude-account-report)
describe the current screens and data.
