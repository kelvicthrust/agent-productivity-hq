# Candidate for independent Verification

## Scope

Historical candidate covering implementation milestones M1–M10. No current runtime assessment
is recorded here. The historical author checks used Node 26.3.1 on macOS and pnpm 11.25.0. The
[current README](../../../README.md#run-from-source) gives the install, build and start commands.
Default serving is loopback on port 4317.

See the [execution record](execution-record.md) for milestone outcomes, the
[delivery build record](../delivery/build-record.md) for the later findings, and
[synthetic fidelity evidence](../../implementation/evidence/m10/README.md) for the retained Setup
examples.

## Known gaps

1. **M10_MATRIX and M10_PACKET_ID.** The historical checks did not form a complete matrix on
   an independently identified final candidate.
2. **M10_PERFORMANCE.** First-import responsiveness and native-browser chart timing remained
   unverified. Headless chart runs included relayout samples above 16 ms. See the
   [chart redraw report](../../implementation/evidence/chart-redraw-runs.md).
3. **M10_START.** Real-listener startup and first-launch browser completion on a clean macOS
   installation remained unverified.
4. **M10_VISUAL_DIFF and M10_VISUAL_COVERAGE.** Setup, recovery and Delivery differences
   persisted, and the author’s comparison did not replace independent all-width coverage.
   The detailed fidelity notes are excluded from this snapshot.
5. **Earlier review findings.** Corrections followed findings on E8 credential handling and
   symlink writes, coverage and Retry states, local token parity, unreadable-count persistence,
   GitHub rate limits and drill-down dates. No complete subsequent review established closure.
6. **Real-source findings.** E1 and E2 failed their ccusage comparisons. E3 and E5 were not-run.
   E4’s one-day overlap comparison failed. E6’s minimum-permission check failed and was waived
   for broader grants. E8 ran only legacy status-line setup, with fixture and documentation
   coverage accepted for the remaining criteria. Private reports are excluded.

## Simulated, stubbed, not-run

- Synthetic or scripted coverage included provider histories, Paseo, GitHub, Codex app-server and
  temporary Claude profiles. Browser comparisons use invented data.
- Historical not-run boundaries included real-socket startup, native-browser and real-device
  behavior, manual VoiceOver, live Paseo, live Claude status-line data and transcript attribution.
- The historical GitHub and ChatGPT provider checks covered limited cases. The private findings
  and underlying usage records are excluded from the public snapshot.

## Limits, decisions, recovery

The historical run used headless Chromium with software rendering. The 16 ms budget applies to
the unrounded maximum in each complete class. An incomplete run is inconclusive. The relayout
exception applies only to the pinned headless browser. Native-browser timing remains unassessed.

See the [decision report](decision-report.md) for context and the
[local setup guide](../../delivery/setup.md#when-something-is-wrong) for recovery procedures.

## Verification should target

- Record the exact assessed revision and run the declared [checks](../../../README.md#checks).
- Exercise fresh startup on a real macOS listener, finish Setup in a browser and reach Overview.
- Compare the product with the accepted design at 1280, 390 and 320 pixels, including the Setup
  step marker, recovery and Delivery evidence surfaces.
- Measure native-browser chart redraw and first-import responsiveness. Compare complete chart
  classes against the 16 ms ceiling.
- Reassess the earlier corrections and exercise authorized real-source boundaries for GitHub,
  Paseo, Claude Code and local-history reconciliation.
