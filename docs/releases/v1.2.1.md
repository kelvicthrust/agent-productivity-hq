# What's new in v1.2.1

- **See Claude Code background work in HQ.** Open **Sources & repos** and turn on **Report Claude Code background work** after enabling the wait hooks. In Paseo, use **Open owner settings** from the same card. HQ shows subagents, shell jobs, and monitors Claude reported when its turn ended, with the time of the last report. Older reports appear under **Recent idle**. Open `/tasks` in Claude Code to check current status between reports.
