# What's new in v1.2.0

- **Turn agent work into an update.** Open the **Work Review** card in **Overview** to read and copy a work summary backed by links to session and pull request evidence. Use **Delivery → Work Review** to generate updates or browse saved versions. Generation requires a separate ChatGPT sign-in and sends selected session excerpts and pull request metadata to OpenAI. In Paseo, choose **Overview → Open Work Review** to open the owner dashboard with your current filters. [Work Review setup](https://github.com/kelvicthrust/agent-productivity-hq/blob/main/docs/delivery/setup.md#connect-work-review)
- **Keep this week’s review up to date.** Turn on **Keep this week up to date** in **Delivery → Work Review**. While HQ runs, it can refresh the current week when evidence changes, at most once every six hours using your ChatGPT allowance. Automatic refresh covers **My PRs**, all repositories, and both agent providers.
- **Spot work that needs you in Paseo.** On supported clients, the **Needs your answer** badge marks workspaces with pending input and clears when you resolve it. In HQ, the main agent can show its Paseo workspace title, and subagents show their recorded names when available.
- **Check your installed version from the browser.** The **About Agent Productivity HQ** button in the app bar shows the version and links to release notes and troubleshooting. Weekly quota cards also make the percentage of the limit used easier to scan.
